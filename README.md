Setup
Prerequisites

n8n instance (local or cloud)
Groq API key — get one here
Telegram bot token — create one via @BotFather

Steps

Clone this repo and import My_workflow.json into n8n:

Open n8n → Workflows → Import from file


Add your credentials in n8n:

Telegram API → paste your bot token
Groq API → paste your Groq API key


Activate the workflow — the bot is now live.
